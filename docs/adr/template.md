# ADR NNNN: A claim, not a topic

- **Status**: Proposed
- **Date**: YYYY-MM-DD
- **Supersedes**: (ADR number, or omit)
- **Superseded by**: (filled in later, or omit)

## Context

What forces the decision. Constraints, the pressure that made the status quo
untenable, and anything a reader needs in order to disagree usefully. Name the
issue or pull request where the argument happened.

## Decision

One paragraph, stated in the present tense as a rule the repository follows.
Then the specifics: what is in scope, what is explicitly out.

## Consequences

What this buys, and what it costs. The cost half is the useful half: name the
thing that is now harder, the workaround people will reach for, and the failure
mode to watch. A record with no downsides listed has not been thought through.

## Enforcement

What fails when somebody breaks this, and where. A test path, a static-analysis
rule, a CI job. If the answer is "nothing", say so and explain why the decision
is still worth recording.

## Alternatives considered

Each with the reason it lost. "It was never considered" is a legitimate entry
when true.
