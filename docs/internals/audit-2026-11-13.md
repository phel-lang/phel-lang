# Audit continuation, 2026-11-13

The second pass for [#3723](https://github.com/phel-lang/phel-lang/issues/3723) produces 24 new findings: three `p1`, seventeen `p2` and four `p3`. Each linked issue contains a command that reproduces the problem, actual and expected output, a source location, a proposed fix and an acceptance check. All 24 saved reproduction blocks reproduce the reported failures at the audited revision.

The audited revision is [a5d3d283c](https://github.com/phel-lang/phel-lang/commit/a5d3d283c60692154e4c449792c3cbb500059d2a), on macOS arm64 with PHP 8.5.12. This report records the read-only sweep; fixes belong to the linked issues.

## Original findings

All 59 original issues, #3664 through #3722, are closed. GitHub's closing-PR links confirm merged fixes for 58. That decision remains in force.

## Coverage

- Reader and analyzer: bounded probes cover 1,000 and 10,000 nested lists, 2 MiB and 8 MiB strings, reader/printer round trips, malformed tokens, regex termination, quasiquote and nested rest/`:as` destructuring. Deep nesting and large-string probes complete before their subprocess deadlines. The CLI overrides PHP memory-limit flags, so these runs do not establish a memory ceiling. Vector splicing, auto-gensym reuse and nested quasiquote checks pass. A leading BOM remains unsupported; bare backslash forms remain symbols. No new support contract is assumed for those spellings. Unterminated regex input fails with `PHEL310` rather than hanging; its message remains generic.
- Collections and lazy values: seeded randomized map tests run 1,500 operations each with normal and constant hashes, checking puts, removals, counts, lookups, transient round trips and 79 saved snapshots. The constant-hash run isolates the nil-value lookup defect; no other model mismatch appears. Nested lazy thunks realize once on the same sequence, finite ranges terminate, and a consumed head is released while its tail remains live.
- Performance candidates: namespaced symbols with the same name share a hash, lazy/chunked sequence hashes recompute, and the keyword intern table retains 1,000 discarded test names. These observations alone do not establish a correctness defect or a measured performance regression. Transient path copying remains the deliberate, measured decision in [#3171](https://github.com/phel-lang/phel-lang/issues/3171).
- Standard library: Unicode reverse, substring and regex replacement, positional `format`, HTML escaping and explicit raw strings, strict base64 decoding, URI round trips and ordinary exception assertions pass. JSON error flags, depth limits, duplicate-name handling and `JSON_BIGINT_AS_STRING` follow the existing PHP-backed behavior. The table above tracks the separate shape, numeric-value, conditional-rendering and assertion defects.
- Watch and interop: real temporary-tree probes cover a symlink cycle, extension filtering and deletion. Polling create/delete/modify and debounce tests pass. A real child-process probe exposes the external-watcher pipe defect; documented fswatch byte records expose its separate framing defect. Interop tests cover by-reference and named arguments, native enums, readonly values, hydration and keyword-to-string coercion.
- Network and editor: nREPL malformed, incomplete, deeply nested and oversized messages, slow readers and complete responses pass focused tests. LSP checks cover CRLF and UTF-16 edits, Windows URI conversion, invalid UTF-8 responses, buffered diagnostics, debounce and document closing. The separate Unicode navigation failure is filed above.
- Tooling and CLI: balance, lint, doc, formatter parse-failure status, mutation-worker timeouts and stderr flooding, fiber bindings, stdin, non-UTF-8 script arguments and `--flag=value` forwarding receive focused checks. Lint/doc JSON parses on valid fixtures. The table records the failing metadata repair, prefixed global options and profiler cases.
- Build and run: the build suites exercise same-second source changes, scan reuse, transitive macro invalidation, concurrent graph persistence, unsafe cache clearing and namespace collisions. The current-source PHAR builds successfully and reports `v0.54.0-beta#a5d3d28`. From `/tmp`, it runs arithmetic and stdin eval, `read-string`, `load-string`, `phel.json`, absolute script paths with option-like and non-UTF-8 arguments, and namespace-relative `load` files.

## File metadata count

The 50-file warm namespace-index validation makes 56 PHP `url_stat` calls and opens zero directories. This measures the scan phase used by a warm command, using the repository's existing stream counter. It counts indexed-file and directory stamp checks; it does not count native system calls or the rest of CLI startup.

The measurement command is:

```sh
php <<'PHP'
<?php
require 'vendor/autoload.php';
$code = (new PHPUnit\TextUI\Application())->run([
    'phpunit',
    '--filter=test_fifty_file_warm_scan_opens_no_directories',
    'tests/php/Unit/Build/Application/CachedNamespaceExtractorScanIndexTest.php',
]);
echo json_encode([
    'metadata_operations' => PhelTest\Support\CountingScanFileStream::$stats,
    'directory_opens' => PhelTest\Support\CountingScanFileStream::$directoryOpens,
]), PHP_EOL;
exit($code);
PHP
```

The test passes with five assertions and prints `{"metadata_operations":56,"directory_opens":0}`. A native whole-command syscall count remains unmeasured: `dtruss -t stat64 /usr/bin/true` fails with `DTrace requires additional privileges` on this host. This environment limit does not change the measured decision in #3704.

## Limits

The probes use finite inputs on PHP 8.5/macOS. Native fswatch and inotifywait binaries are unavailable, so external backend delivery is checked through a real substitute process and documented protocol frames. Windows behavior is covered by URI unit cases, not a Windows runtime. Dense escape-heavy input, production load, uncontrolled network peers and sustained memory pressure are outside these bounded checks.
